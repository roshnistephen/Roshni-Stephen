Profile

Interface-first developer with an eye for detail

I'm a front-end developer and UI expert based in Kerala, India. My work sits where design meets code — turning layouts, brand ideas and rough sketches into interfaces people can actually use, on the web and on mobile.

Over 2+ years I've shipped 10 live projects end to end: interface design, front-end build, responsive behaviour and deployment. I build with HTML5, CSS3, JavaScript, jQuery and Flutter, and I care about the small things — a button that responds the way you expect, type that reads well at every size, a page that loads before you notice it.

  • UI design and front-end build handled by one person — no handover gap
  • Pixel-perfect across browsers, breakpoints and devices
  • Accessibility and performance built in, not bolted on
  • Clear communication and on-time handover
